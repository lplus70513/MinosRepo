# MinosRepo
### 1. 游戏背景简介
- 在另一条时间线上，雅典王子忒休斯并没有成功走出迷宫，系在迷宫入口的绳子也垂了下来。希腊得知消息后举国悲痛，经过秘密规划后，从希腊出发的刺客成功刺杀了米诺斯国王，埃勾斯国王重新召集大量军队攻占了克里特岛。考虑到破坏迷宫可能会释放出怪物造成更大的破坏，同时为了寻找王子，国王开始在全国范围内召集有能力的，敢于进入迷宫的勇士。
#### 2.1 游戏玩法简述
- 本游戏是一个肉鸽+战旗元素的闯关类游戏，大致有3层，每层有4~7圈正六边形，每层中有战斗、宝箱、雕像等不同的事件格，在每层中，玩家有一定的步数限制，通过线的数量来体现，当步数清零时，玩家也会死亡。玩家通过一系列决策闯过层层关卡到达关底挑战boss。
